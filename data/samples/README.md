# 테스트용 실제 샘플

무신사 등에서 가져온 **옷 사진 + 치수표 스크린샷**을 여기에 둔다.

```
tshirt.jpg          옷 사진
tshirt_chart.png    치수표 스크린샷
pants.jpg
pants_chart.png
```

**이 폴더의 이미지는 커밋하지 않는다** (`.gitignore`). 쇼핑몰 상품 이미지는
저작권이 있어서 공개 저장소에 올리면 안 된다. 발표 자료에 쓸 때도 출처를 밝힌다.

치수표에서 뽑아낸 **숫자**는 저작물이 아니므로 `data/size_charts/*.json` 으로
정리해 커밋해도 된다.
